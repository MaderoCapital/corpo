# Madero Capital · Locales comerciales

Web pública (`index.html`) y portal de marcas (`portal.html`) de Madero Capital.

- **Web pública**: descripción, mapa de búsquedas activas (solo ubicación y superficie) y formulario para que los propietarios postulen locales.
- **Portal de marcas**: cada marca entra con mail y contraseña y gestiona sus búsquedas. El equipo de Madero aprueba las cuentas nuevas.
- **Datos**: Supabase (ver `supabase/schema.sql`). Los permisos por fila garantizan que cada marca vea solo lo suyo.
- **Mapa**: calles de la Ciudad (datos abiertos GCBA, CC-BY 2.5 AR) y del resto del país (© colaboradores de OpenStreetMap, ODbL).
